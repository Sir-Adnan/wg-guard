PASS Native: the dedicated wg-guard journal namespace was active with the
installer-owned 7-day, 1-day-file, 128 MiB persistent and 64 MiB runtime limits.
The operation directory was 0700, records were 0600, and systemd-tmpfiles removed

and SIGINT follow cancellation succeeded. A forced service-process crash advanced
the restart counter and recovered readiness.

PASS Docker: exact-commit GitHub source installation and update produced matching
host/container build identities. The container used restart=unless-stopped and the
local logging driver with compression, max-size=16m and max-file=8. A real process
crash advanced the restart counter and recovered readiness. The host CLI emitted
both container output streams through one redirectable log stream; this drill found
and closed that Docker stderr regression before the final run. Injected compose-up
failures during update and rollback both returned failure, recovered the healthy
container automatically, and produced fixed failed operation records.

PASS live behavior in both modes: an isolated kernel AmneziaWG client completed a
real handshake and sustained traffic. The API reported healthy traffic rates near
49.5 KiB/s, one online user, one active peer, and a maximum observed scheduler gap
of 10.05 seconds. A 64 MiB memory/CPU load was reflected in telemetry. Removing the
owned test interface produced degraded health with awg_interface_missing; restart
reconciled it. Missing/reset/replacement rate suppression also remains covered by
the deterministic unit/race suite rather than inferred from a graph.

PASS resource/UI gate: Native idle CPU was 0.067%, process RSS 31,004 KiB and API
p95 2.312 ms. Docker idle CPU was 0.100%, process RSS 30,760 KiB and API p95
1.807 ms. The authenticated Docker live fragment was 6,606 bytes and rendered four
operational cards. The fixed 180-point ring remains below its tested 128 KiB cap.

the expected closed components. Captured service diagnostics contained neither the
actual short-lived API token nor the administrator password; a synthetic capability

PASS cleanup: purge-all removed the container, state, data, host manager, retention
policy and exclusively owned packages/source. Harness namespaces, links, wrappers,
