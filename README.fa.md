وی‌گارد کارهای روزمرهٔ ادارهٔ یک نود VPN را در پنلی واکنش‌گرا و دوزبانه جمع می‌کند.
معماری آن سبک است: زبان Go، پایگاه SQLite، صفحه‌های رندرشده روی سرور، HTMX و
جاوااسکریپت محدود. مسیر انتقال دادهٔ VPN روی میزبان می‌ماند و پنل مدیریت دسترسی،
تحویل کانفیگ، عیب‌یابی و بازیابی را در یک جا قرار می‌دهد.

| نشان | امکانات اصلی |
|---|---|
| 🛡️ | **مدیریت AmneziaWG:** اینترفیس با بازه‌های IPv4 مرتب‌شده و نمایش ظرفیت، پروفایل‌های ضد DPI، همتاها و همگام‌سازی کنترل‌شدهٔ میزبان |
| 👥 | **چرخهٔ کاربر:** قالب فنی اختیاری، افزایش حجم، انقضا، آغاز از نخستین اتصال، دستگاه، سقف سرعت، بازنشانی مصرف، پلن بعدی و تعویض امن لینک اشتراک |
| 📱 | **تحویل به کلاینت:** کانفیگ و کد QR هر دستگاه، دانلود گروهی و صفحهٔ اشتراک عمومی ساده |
| 📈 | **دید عملیاتی:** سلامت نود و هسته، پردازنده، حافظه، دیسک، نرخ زنده، تاریخچهٔ ترافیک و عیب‌یابی |
| 🔐 | **عملیات امن:** دسترسی جداگانهٔ مالک و رسیلر، توکن API سطح‌بندی‌شده، وبهوک امضاشده، پشتیبان رمزنگاری‌شده، به‌روزرسانی و بازگشت |
| 🧹 | **نگهداری با بازبینی:** پاکسازی ترکیبی کاربران و تاریخچه با فیلتر وضعیت، مالک و تاریخ، پیش‌نمایش اثر عملیات و مدیریت فضای پایگاه داده |
| 🌐 | **رابط کاربری پخته:** فارسی و انگلیسی، راست‌به‌چپ و چپ‌به‌راست، انتخاب اعداد انگلیسی یا فارسی، حالت‌های روشن و تیره، ده پریست بصری، دسکتاپ و موبایل |

> ریفکتور شاخهٔ `main` فقط Docker را برای تولید نگه می‌دارد و هنوز منتشر نشده است.
> نسخهٔ پایدار `v0.1.9` برای آماده‌سازی و گرفتن بکاپ است؛ پیش از بازسازی سرور،
> بکاپ را با مدیر همان نسخه بگیرید و نسخهٔ بیرون از سرور را بررسی کنید.

### نصب

**محیط تأییدشدهٔ تولید:** اوبونتو ۲۴٫۰۴ روی پردازندهٔ amd64، با دسترسی ریشه یا sudo و
نقطهٔ اتصال VPN قابل‌دسترسی. نسخهٔ منتشرشده روی این محیط تأیید شده؛ استقرار جدید Docker به پذیرش جداگانه نیاز دارد. نصب‌کننده پیش‌نیازهای ثبت‌شده را بررسی و در صورت انتخاب شما آماده می‌کند.
دسترسی کنسول یا SSH را هنگام نصب حفظ کنید و برای HTTPS دامنه‌ای آماده داشته باشید.

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/Sir-Adnan/wg-guard/main/install.sh | bash'
```

این دستور اسکریپت ورودی روز را دریافت می‌کند و **آخرین انتشار پایدار** را نصب می‌کند؛
نسخهٔ توسعهٔ شاخهٔ `main` را نصب نمی‌کند. نصب‌کنندهٔ انگلیسی استقرار Docker، حساب مدیر و دسترسی HTTPS یا خصوصی را راهنمایی می‌کند و فایل انتشار را پیش از
نصب بررسی می‌کند. مدیر محلی پس از نصب نیمه‌تمام نیز باقی می‌ماند تا ادامهٔ کار از
`sudo wg-guard` ممکن باشد.

| هدف شما | روش |
|---|---|
| **آخرین انتشار پایدار با راهنما** | دستور بالا را اجرا و گردش کار Docker را دنبال کنید. |
| **بازبینی پیش از اجرا** | اسکریپت را با دستورهای پایین دریافت و بخوانید، سپس محلی اجرا کنید. |
| **نسخهٔ مشخص یا کد توسعه** | برچسب انتشار یا شناسهٔ کامل commit را صریح انتخاب کنید؛ [راهنمای نصب](docs/operations/github-install.md) را ببینید. |
| **نصب خودکار** | گزینه‌های نصب و فایل محافظت‌شدهٔ گذرواژهٔ مدیر را بدهید؛ [راهنمای ترمینال](docs/operations/terminal-management.md) را ببینید. |

| روش دسترسی به پنل | زمان انتخاب |
|---|---|
| **تونل خصوصی SSH** | زمانی که دامنه آماده نیست؛ پنل فقط روی آدرس محلی میزبان می‌ماند. |
| **دسترسی HTTPS مدیریت‌شده** | زمانی که دامنه یا گواهی پشتیبانی‌شدهٔ IP عمومی دارید. |
| **پروکسی معکوس موجود** | زمانی که Nginx یا پروکسی HTTPS دیگری را خودتان مدیریت می‌کنید. |

برای بازبینی اسکریپت پیش از اجرا، آن را جداگانه دریافت کنید:

```bash
curl -fsSLo wg-guard-install.sh \
  https://raw.githubusercontent.com/Sir-Adnan/wg-guard/main/install.sh
less wg-guard-install.sh
bash wg-guard-install.sh
```

راهنمای [نصب از گیت‌هاب](docs/operations/github-install.md) نسخهٔ مشخص، ساخت توسعه و نصب خودکار
را همراه با پیش‌نیازها و بررسی صحت فایل‌ها توضیح می‌دهد.

### گام‌های نخست در پنل

- **سلامت نود** را در داشبورد و خروجی `sudo wg-guard doctor` بررسی کنید.
- **اینترفیس** را بسازید و پروفایل ساده یا سازگار با AmneziaWG را انتخاب کنید.
- **کاربر** را اضافه کنید؛ قالب فقط برای تنظیمات فنی مشترک است. ربات مالک می‌تواند مشخصات اشتراک را مستقیم بفرستد و کالاها و قیمت‌های خود را بیرون از WG-Guard نگه دارد.
- **دستگاه** را بازبینی کنید و کد QR، کانفیگ یا لینک اشتراک آن را به کاربر بدهید.

تعویض لینک اشتراک، کلیدهای دستگاه‌های همان کاربر را هم عوض می‌کند تا لینک و کانفیگ
قدیمی دیگر کار نکنند. پیش از تغییر پروفایل فعال، سازگاری کلاینت را بررسی کنید.

### مدیریت

```bash
sudo wg-guard             # منوی مدیریت
sudo wg-guard status      # وضعیت سرویس و استقرار
sudo wg-guard doctor      # عیب‌یابی میزبان و تونل
sudo wg-guard logs        # گزارش‌های عملیاتی محدود
sudo wg-guard update      # به‌روزرسانی بررسی‌شدهٔ پنل و هسته
```

مدیر محلی پشتیبان‌گیری رمزنگاری‌شده، بازبینی بازیابی، زمان‌بندی، بازگشت نسخه، تغییر
دسترسی و حذف را هم انجام می‌دهد. پیش از انتقال پنل به سرور دیگر پشتیبان بگیرید؛
بازیابی محیط مقصد را بررسی می‌کند و رابطهٔ پایگاه داده با کلید اصلی را حفظ می‌کند.
جزئیات در [راهنمای بازیابی](docs/operations/backup-restore.md) آمده است.

پروفایل‌های مبهم‌سازی‌شده به کلاینت سازگار AmneziaWG نیاز دارند؛ پروفایل ساده با
کلاینت معمولی WireGuard کار می‌کند. فایروال firewalld فعال، نسخه‌های جدیدتر اوبونتو،
معماری‌های غیر amd64 و آزمون هزار اتصال هم‌زمان در ادعای تولید این نسخه نیستند.
دامنهٔ دقیق آزمون‌ها در [وضعیت پروژه](docs/development/status.md) آمده است.

### رابط برنامه‌نویسی و معماری

رابط مستند `/api/v1` برای اتصال سامانه‌های دیگر در دسترس است. خرید اتمیک، کاربر و دستگاه و
لینک مشتری را می‌سازد؛ افزایش حجم نیز نتیجهٔ پیش‌وپسِ قابل‌بازیابی دارد. توکن رسیلر
فقط به مشتریان همان رسیلر
دسترسی دارد. صفحه‌بندی، رسید تحویل و وبهوک امضاشده اتصال ربات یا پنل فروش را آسان می‌کنند.
پنل همچنان روی سرور رندر می‌شود و میزبان مالک اینترفیس، فایروال و محدودسازی
سرعت است. از [قرارداد API](docs/architecture/api.md) یا [نمای معماری](docs/architecture/overview.md)
شروع کنید.
